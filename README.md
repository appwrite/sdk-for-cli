# Appwrite CLI (Go)

Appwrite is an open-source self-hosted backend server that abstracts and simplifies complex and repetitive development tasks behind a very simple REST API

Generated by [appwrite/sdk-generator](https://github.com/appwrite/sdk-generator).
Do not edit by hand -- change `templates/go-cli/` and regenerate:

```bash
php example.php go-cli
```

## Build

Generated Go is formatted after generation rather than emitted pre-formatted --
Twig cannot reliably produce gofmt's struct-field alignment, and `gofmt` is
idempotent, so formatting is a build step rather than a template concern.

```bash
gofmt -w .
go mod tidy
go build -ldflags="-s -w" -o appwrite .
./appwrite --help
```

## Status

Work in progress. This CLI preserves the TypeScript implementation's command
surface exactly -- every command path, flag name, shorthand and alias -- and
its `--json`/`--raw` output byte for byte, so scripts written against one keep
working against the other.
